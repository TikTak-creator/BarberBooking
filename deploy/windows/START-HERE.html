Ваш сервер.
Без ручной настройки базы.

Сайт записи, отдельный MySQL и понятное управление — в одном комплекте.

01 / Настройте один раз

  1. Откройте Bladez.Host.exe или ярлык Bladez Host после установки.
  2. Введите название барбершопа, имя владельца, логин и свой пароль. Пароль: 12–128 символов, большие и маленькие латинские буквы, цифры, не меньше пяти разных символов.
  3. Оставьте порты по умолчанию и нажмите Настроить и запустить. Интернет нужен для загрузки официального MySQL (~281 МБ). Если требуется компонент Microsoft VC++, программа предложит установить включённый подписанный файл.
  4. Дождитесь состояния Работает: сайт и база и нажмите Открыть сайт. Войдите с созданным логином.

02 / Подготовьте салон

В настройках укажите настоящие контакты, часовой пояс и правила отмены. Отредактируйте примеры мастеров и услуг. Создайте отдельные аккаунты сотрудникам. В профиле владельца подключите второй фактор и сохраните резервные коды.

Этот комплект по умолчанию открывает сайт только на данном компьютере: 127.0.0.1. Для публичной записи нужен HTTPS и домен. Готовый вариант Linux/VPS находится в другом комплекте релиза. Не открывайте MySQL и обычный HTTP в интернет.

03 / Запускайте и сохраняйте

Сервер работает, пока открыто окно Host или его значок в трее. При выходе программа останавливает принадлежащие ей сайт и MySQL. Выход из Windows и сон компьютера прерывают доступность.

Кнопка Создать резервную копию сохраняет базу вместе с ключом шифрования в защищённом файле. Нужен отдельный пароль от 12 символов. Пока копия создаётся, сервер ненадолго останавливается. Включённый инструмент поддерживает до 512 МиБ исходных данных.

Проверяйте восстановление в новую пустую папку. Существующая база не перезаписывается. Без ключа или пароля копии контакты восстановить нельзя. Старые браузерные сеансы при восстановлении сбрасываются.

Не удаляйте папку данных %LOCALAPPDATA%\Bladez\Host. Обновление/удаление программы не должно удалять её. Простое копирование ключа другому пользователю Windows не заменяет зашифрованную резервную копию.

Если что-то не запускается

Проверьте интернет, свободное место, занятые порты и Microsoft VC++ x64 Runtime. Существующий системный MySQL программа не меняет. Не удаляйте ключ или базу при ошибке. Технический журнал отдельной базы: mysql-data/mysql.err. Не публикуйте его вместе с паролями и ключами.

При потере входа владельца используйте Восстановить доступ владельца в локальном окне Host: потребуется существующий логин и новый пароль. Это сбросит старые сеансы и MFA; подключите второй фактор заново.

English quick start

Open Bladez.Host.exe. Enter the shop/owner details and a unique 12–128 character password with uppercase/lowercase letters and digits. Choose setup/start; the wizard provisions its own verified MySQL. .NET is included. A signed Microsoft VC++ prerequisite may require elevation.

Open the website, sign in, replace example catalog entries, configure policies and staff, enable owner MFA, then create and test an encrypted backup. Windows hosts locally while the window/tray and Windows session remain active. For a public always-on HTTPS website use the Linux/VPS package. Preserve the private profile and its key. Restore only into a fresh empty profile; the included backup tool supports up to 512 MiB of source data. Read the linked full guide before real business use.
